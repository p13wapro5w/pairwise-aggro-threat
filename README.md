# pairwise-aggro-threat

Boss 追着治疗跑，坦克怎么打都拉不回来，仇恨表只累加伤害，治疗的有效治疗量没按威胁系数折算；嘲讽写入了仇恨但三秒后没锁定，Boss 转身又走；范围检测用圆形，隔着墙也能建立仇恨；玩家死亡后仇恨没清，复活瞬间被全场追；持续伤害每跳都加一次仇恨，dot 职业把 Boss 钉死；宠物的仇恨算在主人头上，换宠后数值残留；多个坦克交替嘲讽，仇恨表按最后写入覆盖而不是叠加；Boss 切换阶段时仇恨表重建，治疗直接接管；超出追击范围后仇恨缓慢衰减，但衰减只对伤害来源生效；切目标时有 0.5 秒硬切窗口，嘲讽在这个窗口内无效。gameplay/aggro_threat.py 是核心，tests/test_aggro_threat.py 15个红。要修的是：治疗按系数折算；嘲讽加锁定时间；仇恨建立查视线；死亡清表；dot 按施法者合并；宠物仇恨独立归属；嘲讽叠加不清零；阶段切换保留比例；衰减对所有来源；硬切窗口内可嘲讽。

## 运行

```bash
python -m pytest tests -q
```
